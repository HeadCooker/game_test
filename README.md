# 异星撤离 / Alien Evacuation · v0.5.0

六关剧情塔防 + 三站随机远征的 Windows 单机原型。固定使用 Godot 4.7.2 stable、GDScript、Compatibility。

## v0.5 主动防守更新

- 16×16正方形地图，手动开波，无准备倒计时。战役每关4–6波，远征每站5波；同种敌人的血量不随波数增加。
- Q选择地雷（15合金，最多8枚），点击空地放置，敌人接近时范围引爆；E选择免费轰炸，点击地图施放，25秒冷却。右键取消瞄准。
- 采矿机每5秒生产4合金，最多存40，点击建筑手动收货；准备和暂停不生产。采矿目标统计已收取的合金，记得及时领取。
- 裂囊虫死亡分裂三只幼虫，幼虫不掉合金。后期数量和组合增强，击杀与过波奖励适度下调。
- 本版调整了地图和波次，旧的进行中任务继续时会迁移建筑坐标；建议从舰桥重新出发体验新版，永久解锁和档案保留。

## 从这里开始

**同学试玩：Windows 10/11 64位，克隆本仓库后双击根目录的 `开始游戏.cmd` 即可。无需安装 Godot、无需编译、无需下载开发工具。** 首次运行会自动解压仓库自带的游戏包，稍等片刻即可进入游戏；更新仓库后再次双击也会自动更新游戏文件，保留个人存档。

不使用 Git 的同学，可以在 GitHub 点击 **Code → Download ZIP**，完整解压文件夹后双击 `开始游戏.cmd`。也可以只下载 `release/AlienEvacuation-Windows-x64.zip`，解压后运行其中的 `AlienEvacuation.exe`，保留同目录的 PCK 文件。请勿只下载单个启动脚本。

1. 退出旧游戏窗口，双击根目录的 **开始游戏.cmd**。
2. 新版首先进入“渡鸦号 / 防务舰桥”，选择档案，再进入 **战役**。
3. 点击第一颗金色任务节点或“01 坠落信号”，阅读简报，在配置页点击出发。页面内容较长时可用鼠标滚轮。
4. 第一关只有机枪、围墙与采矿机。过关逐步解锁装备，第三关开放远征，第六关完成故事并开放困难远征。

自动解压后的程序位于 `build/player/AlienEvacuation.exe`。可分享的独立包为 `release/AlienEvacuation-Windows-x64.zip`。

## 一局之外

- 三个独立档案，舰桥、星图、简报、装备、通讯档案、成就、外观目录和设置。
- 六张有真实障碍与禁建区的地图，六段剧情、十二份日志、三种任务勋章。
- 最多携带三种已解锁炮塔；围墙和采矿机固定携带。主线解锁全部五种炮塔和三个有代价的核心模块。
- 战役失败不扣局外资源；重试只重新布置本局。合金不会带回舰桥。
- 首次通关固定故事选择；重玩可补勋章和日志，不覆盖本档案的首次故事结果。
- 原型最高波次作为历史保留，不转换成通关或装备解锁。

| 战役任务 | 主要目标 | 新装备 |
|---|---|---|
| 坠落信号 | 四波防守，学习建造 | 火炮 |
| 最后一班接驳 | 五波分批接驳，保护可选信号格 | 减速 |
| 深层回声 | 五波，并累计收货160合金 | 电弧、侦察模块、远征 |
| 静默阵列 | 五波，远程与护盾威胁、观察哨 | 狙击、工业模块 |
| 证据焚毁 | 六波分段解码，选择人员名单或实验证据 | 应急模块 |
| 黑色黎明 | 六波、巢母、最终发射 | 结局、困难远征、纪念外观 |

可选目标与敌人情报在简报中公开。第三关采矿不足会导致任务失败，开采进度会显示在战场上方；开采到的合金仍能正常花费。

## 战斗操作

| 操作 | 功能 |
|---|---|
| 1—7 或右侧建筑按钮 | 选择本次携带的建筑；灰色为不可用 |
| 左键空地 | 建造，绿色可建、红色不可建 |
| 左键建筑 | 查看范围、升级、维修、出售 |
| 右键 / Esc | 取消建造或关闭说明 |
| 空格 | 暂停/继续；暂停可以布防 |
| Enter | 开始下一波，无准备倒计时 |
| 顶部舰桥 | 准备阶段保存退出；战斗中确认后返回本波准备 |

合金来自击杀、过波和手动采矿收货。每台采矿机每累计5秒有效进攻时间储存4合金，点击建筑收货，库存上限40，准备、暂停、说明界面及撤离等待不计时，不足5秒进度跨波保留。
敌人支持斜走、不同路线偏好和长绕路时拆墙，不能穿建筑墙角。留意钻地裂隙、绿色腐蚀弹、蓝色护盾条和首领召唤。电弧连锁破盾，狙击无视盾甲。

## 随机远征

三场独立战斗，战后安全节点可选择临时强化、一次事件和下一条路线。三项选择都确认后才能继续；选择与随机种子会保存，读档不会重新抽取。

- 三站基础徽记分别为10、15、25枚，某些事件有额外收益或代价。
- 主动撤回带走当前未带回徽记；完成第三站自动入库；失败失去本次未带回部分。
- 每站重新初始化核心、建筑和合金，装备配置固定，远征强化持续。
- 六种强化、八个事件、四种环境修正。困难远征在战役结束后开放。
- 外观价格50、100、150徽记。外观与十二个成就都不给永久伤害或生命加成。

## 保存与继续

准备阶段进入时自动存检查点；点击提前迎战还会保存当前布防。准备阶段点“舰桥”或关闭窗口会保存最新建筑、合金、核心、采矿进度和模块状态。
战斗中关闭或返回，继续时回到本波准备，不保存半途战斗。安全节点的远征选择自动保存。

档案保存在 `%APPDATA%/Godot/app_userdata/异星撤离/profile_1.json`（以及2、3）；设置为 `settings.cfg`。文件带版本号、临时文件替换和备份。损坏文件保留为 `.damaged` 并尝试恢复 `.bak`。
主菜单切换档案不会删除旧档案。开始新任务时如有未完成行动，会先提示放弃当前进度。

## 学习与开发

双击 **打开编辑器.cmd**，F5 运行完整舰桥入口，F8 停止。要看最早的独立十波原型，可在编辑器打开 `scenes/main.tscn` 按 F6；它作为开发调试场保留，不用于战役解锁。

- `data/missions/`：六关地形、波次、任务、简报与日志，均为可编辑 Resource。
- `data/expedition/`：远征强化和事件；`data/achievements/`：十二个成就定义。
- `scripts/shell.gd`：舰桥界面；`scripts/campaign.gd`：三档案、奖励、解锁与远征状态。
- `scripts/battle_*`：战斗、经济、波次、界面与存档协调器。
- `scripts/board.gd`：共享网格、岩壁、建造与寻路。
- `audio/`：本项目原创合成环境循环与胜败提示，主音量与背景音乐可在设置中调整。

第一个小练习：在 Inspector 打开 `data/gun.tres`，把 Damage 从12改成18，保存后 F5。比较第一关体验，再改回12。进一步可修改第一关 Resource 的波次或岩壁坐标。

验证与导出：

```powershell
powershell -ExecutionPolicy Bypass -File tools/check.ps1
powershell -ExecutionPolicy Bypass -File tools/export.ps1
```

检查使用 `.tools/` 下的隔离用户数据，不修改正式玩家档案。便携引擎和匹配导出模板在 `.tools/`，不需要编译引擎。

使用电脑正式安装的 Git（本机位于 `C:/Program Files/Git/cmd/git.exe`）。在项目目录完成一个小练习后可执行：

```powershell
git status
git add .
git commit -m "Adjust first mission"
git push
```

首次自己提交前，用 `git config user.name "你的名字"` 和 `git config user.email "你的 GitHub 提交邮箱"` 设置本项目的作者身份。Git 的新安装可能需要重新打开终端才能出现在 PATH 中；也可以用完整安装路径运行。

远端仓库：[HeadCooker/game_test](https://github.com/HeadCooker/game_test)。仓库包含源码和已编译的 Windows 游戏压缩包；引擎、导出模板、测试存档与解压缓存不提交。维护者运行 `tools/export.ps1` 后会同步更新 `release/` 中的试玩包，再一起提交即可。

## 当前边界

这是完整系统与内容流程的原型，不是已通过 Steam 审核的发行成品。画面仍以程序像素图形为主，声音为简短原创合成循环，尚需真人测试、视听打磨与独立设备验收。
3–5小时战役和25–35分钟远征是设计目标，尚未由真人验证；提前迎战会明显缩短时长。没有支付上架费或上传发行平台。
