# 边玩边学

每次只改一件事，试玩后记录结果。不要先背完整的编程语法。

1. **运行与场景**：打开 main.tscn，用 F5 运行。观察场景树根节点和脚本绑定。练习修改游戏标题。
2. **Resource 数据**：调整 gun.tres 的伤害、射程、价格。尝试制作“昂贵但强力”的炮塔，再恢复平衡。
3. **实体和生命**：阅读 enemy.gd 的 setup 和 game.gd 的 hit_enemy。练习给疾行虫增加生命，比较体验。
4. **网格与寻路**：阅读 board.gd 的 can_build、rebuild_routes。围住核心，观察虫群如何拆墙；拆掉一格看路线变化。
5. **信号与界面**：查找 economy_changed 和 refresh_ui，理解数据变化如何通知显示。练习改变资源显示文字。
6. **波次与节奏**：修改 wave_01.tres 的 Count 和 Preparation。让朋友第一次试玩，观察是否有足够的布防时间。
7. **导出**：运行导出脚本，把 zip 发到另一台 Windows 电脑，完整解压后测试。

每一步都保存一个 Git 提交。遇到报错时，复制 Godot 底部 Debugger 的第一条错误和相关代码，再一起定位。
