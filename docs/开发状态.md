# 开发状态与下一阶段

当前交付是 v0.4 六关战役与三站随机远征的程序美术原型，已接入舰桥、装备、档案、奖惩、成就和准备阶段存档。没有支付上架费、创建 Steam 商店或上传发行包。详细状态见 [v0.4 更新说明](v0.4更新说明.md)。

## 后续顺序

1. 亲自试玩，再邀请至少 3 位未接触项目的人试玩，记录通过率、第一座塔摆放时间、失败波次和操作误解。
2. 先依据反馈调节初始资源、塔的性价比、采矿投入的回本时间和波次压力，验证约 20 分钟节奏。v0.3 已恢复战斗内计时采矿、补充怪物攻击反馈，并缓和第四波门槛，下一轮继续检查机制可读性和后期难度。
3. 界面、经济、战斗、波次与快照已拆分为独立协调器；继续维护共享网格和 Resource 配置，避免扩展时退回单一脚本。
4. 引入风格统一且许可明确的像素素材、正式音效、文本本地化和新手引导。
5. 准备阶段自动保存与继续已实现；发布前继续验证版本升级的迁移和真实断电/异常退出恢复。
6. 在目标硬件做 200 敌人压力测试与帧时间分析，验证 1080p 60 FPS，再公布最低配置。
7. 收集独立设备测试结果，再筹备 Steam 账户、商店材料、预告片与发行审核。

## 发布前仍需人工确认

- 十波经济、塔的搭配与最终巢母难度，没有因为测试防线通过而视为已平衡。
- 中文字体当前使用 Windows 的 Microsoft YaHei；其他平台需要正式配置和许可明确的字体。
- Windows 包未签名，正式发行时评估分发流程；不声称已通过 Steam 审核。
- Steam 实际费用、资料与审核要求在发布准备时重新核实。
