# 开发状态与下一阶段

当前交付是可完成单局的程序美术原型。没有支付上架费、创建 Steam 商店或上传发行包。

## 后续顺序

1. 亲自试玩，再邀请至少 3 位未接触项目的人试玩，记录通过率、第一座塔摆放时间、失败波次和操作误解。
2. 先依据反馈调节初始资源、塔的性价比、采矿回本速度和波次压力，验证约 20 分钟节奏。
3. 扩大工程前将界面、经济与波次从主协调脚本拆出；战斗规则继续沿用共享网格与 Resource 配置。
4. 引入风格统一且许可明确的像素素材、正式音效、文本本地化和新手引导。
5. 实现准备阶段自动保存与继续游戏，验证版本升级后的存档兼容性。
6. 在目标硬件做 200 敌人压力测试与帧时间分析，验证 1080p 60 FPS，再公布最低配置。
7. 收集独立设备测试结果，再筹备 Steam 账户、商店材料、预告片与发行审核。

## 发布前仍需人工确认

- 十波经济、塔的搭配与最终巢母难度，没有因为测试防线通过而视为已平衡。
- 中文字体当前使用 Windows 的 Microsoft YaHei；其他平台需要正式配置和许可明确的字体。
- Windows 包未签名，正式发行时评估分发流程；不声称已通过 Steam 审核。
- Steam 实际费用、资料与审核要求在发布准备时重新核实。
