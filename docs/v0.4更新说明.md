# v0.4：渡鸦号战役与随机远征

这一版将独立十波原型接入“舰桥—任务—结算—解锁”的完整循环。已有战斗规则保留；旧版记录不会变成自动通关或全装备解锁。

## 已实现

- 六关剧情与六套真实地形：坠落信号、最后一班接驳、深层回声、静默阵列、证据焚毁、黑色黎明。岩壁阻挡移动与建造，禁建格仍可通行。
- 初始机枪、围墙、采矿机，战役逐步解锁火炮、减速、电弧、轨道狙击。出战最多三种炮塔，三个有代价的核心模块任选一个。
- 开采目标、信号/观察哨标记、分批接驳、分段解码、最终巢母与发射；六份主线记录、六份可选记录、固定主线结局和首次通关故事旗标。
- 三个独立档案、本地成就与进度、外观目录、设置、剧情回看、重试与返回舰桥。长页面支持滚动。
- 任务三勋章：完成、核心生命至少60%、可选目标。重玩可补勋章，不重复解锁装备或改写首次故事结果。
- 三站随机远征、三套复用竞技场、六种临时强化、八个事件、四种环境修正、普通与困难模式。
- 远征安全节点可撤回，三站基础收益10/15/25徽记；事件可能附加收益。失败失去未带回部分，永久成果保留。徽记购买固定价外观，不提供战力。
- 准备阶段自动检查点、出战前保存当前布防、准备阶段保存返回；恢复建筑等级/生命/投资/采矿进度、核心/资源/目标/模块次数及随机状态。安全节点的事件、强化、路线锁定保存，不能读档重抽。
- 原创合成舰桥/战斗氛围循环、胜败提示，主音量、背景音乐、音效、全屏与震动设置。

## 实现结构

任务、波次、炮塔、敌人、事件、强化和成就采用 Resource 数据。`Campaign` 自动加载节点负责档案、唯一结算、解锁和远征，舰桥由独立场景呈现。原单局协调器委托 `BattleCombat`、`BattleEconomy`、`BattleWaves`、`BattleUI` 和 `BattleSave`，网格仍由 `BattleBoard` 共享。

档案带版本号，写入临时文件后替换，保留有效备份；损坏档案尝试恢复并保留 `.damaged`。结算按唯一行动ID去重，成就按实际战斗事件触发，轨道重甲击杀按敌人ID防止读档重复计数。外观只改变绘制颜色。
